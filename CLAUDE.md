# quantic-paris.fr — team website (Quantic, LPENS)

Static Bootstrap 5 site served by GitHub Pages from `main` (repo `QuanticParis/quantic-paris-site`, custom domain in `CNAME`). No build step: what is on `main` is live within 1–2 minutes.

Answer in the user's language.

## Layout
- `index.html`, `research.html`, `people.html`, `publications.html`, `links.html`: top-level pages sharing the same `<head>`, navbar and footer (copy them from an existing page for any new page).
- `main.css`, `main.js`: shared styles/scripts. Edit with care: they affect every page.
- `images/`: photos (people portraits in `images/`, page-specific figures in `images/<name>/`).
- `files/`: PDFs (CVs, etc.).
- `samuel.html`: example personal page, generated by `tools/build_samuel.py` from a CV. Personal pages are `<firstname>.html` at the root.
- `CNAME`: custom domain. Never modify or delete.

## Common tasks
- **Update a people card** (`people.html`): sections Principal Investigators / Technical and administrative staff / Postdocs / Graduate Students / Former members. A card is
  ```html
  <div class="card col-lg-3 text-center">
      <img class="card-img rounded-circle mx-auto" src="images/<name>.jpg">
      <h3><a href="<name>.html">First Last</a></h3>
      <h4>first.last_at_domain.fr</h4>
  </div>
  ```
  Emails are written `_at_` (anti-spam). Moving someone to Former members = moving the card.
- **Add a publication** (`publications.html`): one `<p>` under the right `<h2>YEAR</h2>`, newest first: `Title. Authors. <a href="DOI or arXiv URL" class="link-primary">Journal, volume, page (year)</a>` (or `(preprint) (<a href="https://arxiv.org/abs/…" class="link-primary">pdf</a>)`). Get metadata from the DOI/arXiv page, never invent it. Create the year heading (with an `<hr class="featurette-divider">`) if missing.
- **Personal page**: build `<firstname>.html` in the style of `samuel.html` (hero with photo, research, career, selected publications), from the person's CV or info they give. Link it from their card in `people.html`. Optionally a generator script in `tools/`.

## Rules
- Photos: resize before adding (portraits ~600 px wide, figures ≤ 1600 px, JPEG): `sips -Z 600 in.jpg --out images/x.jpg` on macOS. Keep the repo light.
- Nothing confidential: no unpublished results, grant proposals, internal budgets, personal phone numbers or private addresses.
- Only touch what the user asked for; don't reformat whole files.
- Preview before publishing: `python3 -m http.server 8000` at the repo root, then open http://localhost:8000/<page>.html. Stop the server afterwards.
- Publishing: `git pull`, then commit on `main` with a clear message and `git push` (no pull request needed — team decision 13/11/2026). **Before pushing, show the user the diff summary and get an explicit OK.** After pushing, check the live page (https://quantic-paris.fr/<page>.html) after ~1–2 min.
- If something breaks: `git revert` the commit and push.
- No push access? The user sends their GitHub username to Samuel Deléglise (maintainer) to join the QuanticParis org.
